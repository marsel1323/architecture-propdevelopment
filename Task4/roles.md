# Ролевой доступ к кластеру Kubernetes (RBAC)

| Роль             | Права роли                                                                                     | Группы пользователей        |
|------------------|------------------------------------------------------------------------------------------------|-----------------------------|
| cluster-admin    | Полный доступ ко всем ресурсам и действиям в кластере                                          | DevOps-инженеры, админы     |
| cluster-reader   | Просмотр всех объектов кластера (pods, deployments, secrets и т.п.), без возможности изменения | Аналитики, бизнес-аналитики |
| cluster-editor   | Просмотр и изменение всех объектов, кроме секретов                                             | Backend-разработчики, SRE   |
| secret-reader    | Доступ только к чтению секретов (`secrets`) и config maps в namespace                          | Специалист по безопасности  |
| finance-isolator | Доступ только к namespace `finance`, без прав на другие пространства                           | Финансовая команда          |
| support-reader   | Чтение pod-логов, событий и состояния ресурсов в namespace `production`                        | Поддержка / мониторинг      |
