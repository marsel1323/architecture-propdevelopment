# Требования к внешним интеграциям с партнёрами "Умного дома"

## 1. Требования к безопасности

- Вся передача данных должна быть зашифрована (TLS 1.2+)
- В API недопустима передача открытых персональных данных (например, ФИО, номер квартиры)
- Биометрические данные не должны передаваться напрямую — только через токены или уникальные идентификаторы
- Все действия пользователей должны логироваться на стороне PropDevelopment
- У партнёра должна быть реализована защита от подделки запросов (HMAC, JWT-подписи)

## 2. Аутентификация и авторизация

- Аутентификация по OAuth 2.0 (Client Credentials / Authorization Code Flow)
- Авторизация на основе прав доступа (например, допущен ли конкретный номер авто / биометрия к конкретному дому)
- Обновление access token'ов по refresh-токенам, срок жизни access token — не более 1 часа
- Token Scope должен быть ограничен действиями (например: open_gate, read_logs)

## 3. Взаимодействие между системами

- Tenant-core-app обращается к SmartHome Gateway
- Gateway обращается к API партнёра с использованием подписанного запроса и access token
- Ответ возвращается обратно в мобильное приложение
- Все интеграции через REST API (опционально WebSocket для уведомлений)
- Все события взаимодействия (успешные и ошибочные) логируются и обрабатываются через централизованную систему
